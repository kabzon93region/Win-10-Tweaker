# Чистая комната: утилита настройки Windows

Эта папка — независимая реализация утилиты настройки Windows по документации.
Оригинальный продукт и материалы его разборки здесь не используются и открываться не должны.

## С чего начать

1. Прочитать `AGENTS.md` — правила этой папки.
2. Прочитать `SPEC.md` — что за продукт, требования, архитектура, стек, безопасность, приёмка.
3. Прочитать `FEATURES.md` — полный каталог функций: ID, что применять, как откатывать, риск.
4. Прочитать `TESTPLAN.md` — как проверять результат.
5. Ответить на 3 вопроса из раздела «Открытые вопросы» `SPEC.md` (стек, платная версия, Windows 7).

Промпт для старта чата — в `PROMPT.md` (блок для копирования).

## Что решено, а что решает владелец

Уже зафиксировано в `SPEC.md`:

- подход «данные вместо кода»: каждый пункт — описание в каталоге, а не ветка `if` в интерфейсе;
- снимок и откат каждого действия, проверка результата после применения, идемпотентность;
- запрет скрытых фоновых изменений и опасных удалений без подтверждения;
- отказ от само-переписывающихся обновлений, зашитых паролей и «лицензии по железу»;
- локализация через ресурсы, логи и журнал изменений, тесты на фейковых адаптерах.

Решает владелец до старта:

1. стек: .NET Framework 4.8 + WinForms (совместимость с Windows 7) или .NET 8;
2. нужна ли платная версия и какие функции в неё входят;
3. нужна ли поддержка Windows 7;
4. канал обновлений;
5. нужен ли режим командной строки;
6. название продукта, иконка, подпись кода.
