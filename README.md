# WinTweaker (Твикер Windows)

Независимая реализация утилиты настройки Windows 10/11 по документации: Rust + egui, без платных компонентов.

## Что умеет

- 14 разделов: конфиденциальность, контекстное меню, интерфейс, система, службы, очистка, приложения, автозагрузка, оптимизация, проверка на вирусы, системная информация, сервис, обслуживание, о программе.
- Перед каждым изменением — предпросмотр и подтверждение; необратимые пункты помечены.
- Снимок состояния и откат по журналу `%LocalAppData%\WinTweaker\journal`.
- Фоновое выполнение длительных операций с прогрессом и отменой.
- Профиль настроек (экспорт/импорт списка включённых пунктов).
- Проверка обновлений по последнему релизу GitHub (без скачивания и установки).

## Сборка

Нужны Rust (MSVC) и Visual Studio Build Tools с Windows SDK.

```powershell
cargo build --release -p tweaker-app
```

Готовый файл: `target\release\wintweaker.exe`. Запуск: обычный или с `--section <id>`, `--selftest`, `--smoke`, `--screenshot <png>`.
