# Отчёт о тестировании — этап 4

Дата: 2026-11-25. Версия продукта: 0.1.0.
ОС: Windows 10 Pro 22H2, сборка 19045.6456, x64, учётная запись администратора.
Тестировщик: исполнитель проекта; независимая проверка — аудитор (read-only).
Окружение: текущий ПК владельца (не одноразовая ВМ). Одноразовая ВМ и снапшоты — этап 8.

## Как проверяли

| Что | Как |
|---|---|
| Движок и все 17 пунктов | unit-тесты на фейковых адаптерах: реестр, файлы, службы, задачи, журнал — без изменений реальной системы |
| Чтение реальной системы | `tweak_probe` detect всех 17 пунктов, `schtasks`, `reg query` — только чтение |
| Окно | снимок, сделанный самим приложением (`--screenshot`) |
| Смоук-режимы | `--selftest`, `--smoke`, `--screenshot` копией exe вне папки проекта (`%TEMP%\wintweaker-run`) |
| Память и время старта | замер `--smoke` (debug-сборка) |
| Секреты | поиск ASCII-строк в release-бинарнике |

Реальные записи в службы, задачи и системный реестр на этом ПК в рамках этапа 4 **не выполнялись**: только чтение,
фейки и ранее согласованный обратимый PRIV-13 (этап 3). 🔴-операции — только на одноразовой ВМ (этап 8).
