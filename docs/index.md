# Документация проекта (чистая комната)

Рабочие документы независимой реализации. Требования — в корне папки.

## Навигация

| Документ | Содержание |
|---|---|
| [../README.md](../README.md) | с чего начать, состав пакета, что решает владелец |
| [../SPEC.md](../SPEC.md) | техническое задание |
| [../FEATURES.md](../FEATURES.md) | каталог функций (ID, apply/revert, риск) |
| [../TESTPLAN.md](../TESTPLAN.md) | план тестирования и приёмки |
| [../AGENTS.md](../AGENTS.md) | правила чистой комнаты |
| [STATE.md](STATE.md) | состояние этапов, что сделано и чем проверено |
| [DECISIONS.md](DECISIONS.md) | принятые решения и открытые вопросы |
| [FINDINGS.md](FINDINGS.md) | выясненные по ходу факты и ограничения |
| [CODE_MAP.md](CODE_MAP.md) | карта кода: модули, публичные типы, поток данных |

## Порядок ведения

1. Перед началом этапа — согласовать и записать решение в `DECISIONS.md`.
2. Во время работы — фиксировать существенные факты в `FINDINGS.md` (с доказательством: файл, лог, тест).
3. По завершении этапа — обновить `STATE.md` (статус, артефакт, проверка).
